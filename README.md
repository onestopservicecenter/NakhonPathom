# OSSC นครปฐม — GitHub Pages

## อัปโหลด

สร้าง GitHub repository ใหม่ (สำหรับ GitHub Free ให้เลือก Public) แล้วอัปโหลดไฟล์ `index.html`, `styles.css`, `app.js` และ `README.md` ไปที่ระดับบนสุดของ repository ด้วย Add file > Upload files > Commit changes อย่าอัปโหลด ZIP ทั้งก้อนหรือโฟลเดอร์ครอบอีกชั้น

เปิด Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > Folder: /(root) > Save จากนั้นรอให้ระบบเผยแพร่และคลิก Visit site ในหน้า Pages

## แก้ไข

- `index.html` — เนื้อหาและโครงหน้า
- `styles.css` — รูปแบบ สี และการแสดงผลบนมือถือ
- `app.js` — หมวดงานและการค้นหา

หน้าเว็บนี้มี 9 หมวดและช่องค้นหา แต่ยังไม่เชื่อมบัญชีเจ้าหน้าที่ การกำหนดสิทธิ์ ไฟล์เอกสารจริง หรือระบบอัปโหลด กรุณาอย่าใส่ข้อมูลลับ รหัสผ่าน หรือ API key ใน repository หรือ JavaScript ที่เผยแพร่

อ้างอิง: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
